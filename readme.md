# Верстка сайта Альфа-Банк

 Вёрстка главной страницы `alfabank.ru` для предпросмотра Матвея: 6 блоков, адаптив **1920 → 360 px**, все изображения — реальные CDN-ассеты банка с `alfabank.servicecdn.ru`, лого — оригинальный `webp` от Альфы.

Для верстки сайта была использована нейросеть Claude Code. 

# Хронология разработки

### 1. Базовая вёрстка
Первая итерация: адаптив 1920→360 px, плейсхолдеры для изображений (CSS-градиенты + SVG-иллюстрации), Golos Text как шрифт, дизайн-токены в `variables.css`.
Структура — `blocks/block-N-name/`, `css/`, `js/`.

### 2. Бенто-сетка hero + реальные CDN-изображения
Мзвлечены URL-ы c alfabank.servicecdn.ru, скачано ~50 изображений
(hero-баннеры, карточки продуктов, оферы). Hero переделан
в бенто-сетку 6 колонок × 4 строки с реальными изображениями вместо CSS-градиентов.

### 3. Грид-сетки блоков 4-6 + nav.js
- Блок 4 (сервисы): сетка 2×4 — курсы валют слева на 3 строки, справа карточки сервисов
- Блок 5 (оферы): пилюли-табы, бенто 2×2 в каждом табе
- Блок 6 (о банке): бенто 2×2 — работодатель спанит обе строки слева
- Интегрирован `nav.js` (предоставлен Матвеем): hover-dropdown для desktop-навигации
  с тремя разделами и 6 подразделами «Частным лицам»

### 4. Реструктуризация репозитория
Файловая структура приведена к правильному виду:
`css/` → `styles/` (с переименованием `main.css` → `base.css`), `js/` → `scripts/`,
`blocks/block-N-name/style.css` → `sections/name/layout/name.css` (числовые префиксы
убраны), `assets/images/` → `images/`. 

### 5. Откат CSS к первой итерации
Обнаружена системная проблема: в итерациях 2-3 HTML-классы были заменены на новые
(`product-card-body` → `product-card-info`, `data-tab-panel` → `tab-content`,
изменена структура сервисов, оферов, о банке), но CSS для новых классов написан
не был — отсюда **15+ обращений к несуществующим CSS-классам в HTML**. Решение:
CSS всех 6 блоков восстановлен из первой итерации как база, HTML приведён к именам классов 
первой итерации.

### 6. Финальные правки UX
Логотип: ручные SVG отброшены, использован `images/logo.webp` с сайта банка
Помимо этого множество мелких измений css стилей: измен цвет кнопок, позиция 
элементов интерфейса и тд
